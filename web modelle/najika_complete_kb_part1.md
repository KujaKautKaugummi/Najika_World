## 7. ENTWICKLUNGS-PRINZIPIEN

### Code-Philosophie
```yaml
1. Funktionalität ÜBER Perfektion
   → Erst zum Laufen bringen, dann optimieren

2. Incremental Development
   → Kleine Schritte, kontinuierliche Tests

3. "Don't fix what ain't broke"
   → Funktionierende Teile NICHT anfassen!

4. Token-Effizienz
   → User kurz fragen statt alles neu schreiben

5. Documentation-First
   → Code ohne Doku = vergessen in 2 Wochen
```

### Design-Philosophie
```yaml
1. Player Agency
   → Spieler entscheidet ALLES!

2. Konsequenzen zählen
   → Jede Entscheidung hat Folgen!

3. Chaos is Fun
   → Oregon Trail Events = Chaos = Spaß!

4. No Hand-Holding
   → Tutorial minimal, Learning by Doing!

5. Respect Player Time
   → Kein künstlicher Grind!
```
