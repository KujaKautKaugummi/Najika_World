# ⚔️ PVP-SYSTEM (3 Modi)

## 1. HARDCORE-PVP (Rot) 🔴

### Konzept
```yaml
Typ: Volle Konsequenzen
Risk: ALLES verlieren möglich!
Reward: Höchste (komplett Loot + Ruhm)
Für: Mutige Spieler
```

### Ablauf bei Niederlage
```yaml
1. Lethaler Treffer erfolgt
   → Verteidiger liegt am Boden (noch nicht tot!)

2. System-Prompt erscheint (NUR für Verteidiger):
   "Du wurdest besiegt!
    Biete ALLES an, um zu leben?
    [JA] / [NEIN - Akzeptiere Tod]"

3. WENN Verteidiger wählt JA:
   → Angreifer bekommt Prompt:
   "Gegner bietet ALLES an!
    Akzeptierst du Mercy?
    [ANNEHMEN - Alles nehmen] / [ABLEHNEN - Töten]"

4. WENN Angreifer ANNEHMEN:
   → Double-Confirmation (BEIDE Male "JA" tippen!):
   
   Verteidiger: "Bestätige: ALLES abgeben? (Tippe JA)"
   Angreifer: "Bestätige: ALLES nehmen? (Tippe JA)"
   
5. Transfer:
   → ALLES wird transferiert
   → Verlierer spawnt nackt in Schwarzer Mühle
```

### "ALLES WEG = ALLES WEG" Regel
```yaml
❌ KEINE Ausnahmen!
❌ KEIN Starter-Schwert behalten!
❌ KEINE geschützte Unterwäsche!
❌ KEINE Quest-Items behalten!
❌ Keine "aber das war teuer!"-Ausnahme!

✅ ALLES bedeutet ALLES:
   - Alle Waffen
   - Alle Rüstungen
   - Alle Accessoires
   - Alles Gold
   - Alle Items im Inventar
   - Alle Quest-Items
   - Einfach ALLES!

Nach Mercy:
   → Verlierer muss draußen Stock finden
   → Oder mit Fäusten kämpfen
   → Oder Freunde um Hilfe bitten
   → Oder von vorne anfangen
```

### Mercy-System (Gnade)
```yaml
Cooldown: 7 Tage nach Mercy
  → Wer Mercy erhalten hat, kann 7 Tage nicht wieder Mercy bitten
  
3+ Mercy in 7 Tagen:
  → Automatische Einschränkung
  → Spieler wird auf Softy/Normal begrenzt
  → "Du stirbst zu oft. Wechsle zu Softy-PvP!"
  
Mercy-Counter:
  → Wird in Profil angezeigt
  → "Mercies erhalten: 12"
  → Community kann sehen: "Der stirbt oft"
```

### Respawn nach Tod (ohne Mercy)
```yaml
Tod im Hardcore = Permadeath (für diesen Charakter!)

Konsequenz:
  1. Charakter ist TOT (Permadeath)
  2. Alle Items weg (bleiben bei Killer)
  3. Alle Skills zurückgesetzt
  4. ABER: Neuer Charakter möglich!
  
Neuer Charakter:
  - Start bei Level 1
  - ABER: Account-Bound Achievements bleiben
  - ABER: Kosmetische Items bleiben (Skins, etc.)
```

## 2. NORMAL-PVP (Gelb) 🟡

### Konzept
```yaml
Typ: Mittleres Risiko
Risk: 1 Item verlieren
Reward: Mittel (1 Item + Honor)
Für: Die meisten Spieler
```

### Ablauf
```yaml
1. Kampf bis einer auf 0 HP
2. Verlierer liegt am Boden (nicht tot!)
3. Gewinner wählt 1 Item aus Equipped Gear:
   - Weapon (Links oder Rechts)
   - Armor (Torso)
   - Accessory (Slot)
4. Item wird transferiert
5. Verlierer behält Rest
6. Beide spawnen zurück (Teleport)
```

### Regeln
```yaml
Gewinner-Wahl:
  - 30 Sekunden Zeit
  - Sieht Equipment des Verlierers
  - Wählt 1 Item
  - Kein Gold/Inventar!

Verlierer:
  - Verliert gewähltes Item
  - Behält alles andere
  - Kann sofort weiter spielen
  - Keine Cooldowns
  
Respawn:
  - Beide zurück zu letztem Checkpoint
  - Keine Permadeath-Gefahr
```

## 4. PVP-ZONEN

### Zone-Typen
```yaml
SAFE-Zones (100% PvE):
  - Schwarze Mühle
  - Alle 5 Städte
  - Tutorial-Gebiete
  - Respawn-Points
  → KEIN PvP möglich!

PvE-Default (Opt-in):
  - Open World (meiste Regionen)
  - PvP-Flag setzen = PvP möglich
  - Ohne Flag = unsichtbar für PvP
  → Spieler entscheidet!

PvP-Zones (Always-PvP):
  - Arena (Shadowport)
  - Event-Gebiete
  - High-Loot Dungeons
  → Warnung beim Betreten!
```

### PvP-Flag System
```yaml
Command: /pvp [on/off]

ON:
  - Sichtbar für andere PvP-Spieler
  - Kann angegriffen werden
  - Kann andere angreifen
  - Symbol über Kopf (⚔️)
  
OFF:
  - Unsichtbar für PvP-Spieler
  - Kann NICHT angegriffen werden
  - Kann andere NICHT angreifen
  - Kein Symbol
  
Cooldown: 5 Minuten nach Toggle
```

# 🐾 SLIME-BEGLEITER

## 1. EVOLUTION-SYSTEM

### Stufe 1: Ei (Level 0)
```yaml
Start: Jeder Spieler bekommt Ei bei Level 1
Dauer: 24 Stunden (IRL Zeit!)
Hatching: Zufälliges Fantasy-Tier
```

### Stufe 2: Fantasy-Tier (Level 1-49)
```yaml
Mögliche Formen (8):
  1. Flammen-Hase (Feuer, Speed 12)
  2. Eis-Fuchs (Eis, Speed 10)
  3. Schatten-Spinne (Dunkelheit, Speed 8)
  4. Blitz-Rabe (Blitz, Speed 14)
  5. Wald-Maus (Natur, Speed 9)
  6. Kristall-Eichhörnchen (Erde, Speed 11)
  7. Wasser-Frosch (Wasser, Speed 7)
  8. Wind-Schmetterling (Wind, Speed 13)

Eigenschaften:
  - Element bestimmt Skills
  - Speed bestimmt Dodge-Rate
  - Lernt Skills durch Kämpfe
  - Kann Moves von Gegnern kopieren (10-15%)
```

### Stufe 3: Slime (Level 50+)
```yaml
Trigger: Level 50 + Kritisches Event

Kritisches Event:
  - Besitzer stirbt im Kampf
  - Fantasy-Tier opfert sich
  - Shell/Hülle bricht
  - Slime-Form erscheint!

Metamorphose:
  - Fantasy-Tier "stirbt" (nicht wirklich!)
  - Slime wird geboren
  - Farbe = Region wo Metamorphose stattfand
  - Alle Skills bleiben erhalten
```

### Farben (8 - je Region)
```yaml
1. Blau (Ice Region)
2. Grün (Highland Region)
3. Gelb (Desert Region)
4. Lila (Swamp Region)
5. Weiß (Mountain Region)
6. Cyan (Coast Region)
7. Grau (Caves Region)
8. Rot (Volcano Region)

Special: Braun (Forest Region) - nur Wald-Maus!
```

### Stufe 4: Rainbow-Slime (Ultimate!)
```yaml
Trigger: Sammle alle 8 Farben

Quest:
  1. Besitze 8 Slimes (verschiedene Farben)
  2. Bringe sie zur Schwarzen Mühle
  3. Ritual durchführen
  4. Alle 8 fusionieren
  5. Rainbow-Slime geboren!

Stats:
  - HP: 500 (höchste!)
  - ATK: 150
  - DEF: 120
  - MATK: 180
  - MDEF: 150
  - Speed: 15 (schnellste!)
  - Alle 8 Elemente!
  - Kann ALLE Skills nutzen
```

## 2. SLIME-MECHANIKEN

### Skill-Kopieren (10-15%)
```yaml
Chance: 10-15% pro besiegtem Gegner
Max Skills: 20 im Moveset
Selection: Zufällig aus Gegner-Skills

Beispiele:
  - Feuer-Magier → Feuerball kopiert
  - Drache → Feuer-Atem kopiert
  - Boss → Ultimate-Skill kopiert (selten!)
  
Player-Choice:
  - System zeigt: "Slime hat X gelernt!"
  - Player kann Skill behalten oder ersetzen
  - Wenn 20/20 voll: Alten Skill wählen zum Überschreiben
```

### Befehle (Auto-Mode)
```yaml
Wie Digimon World:
  - "Angriff!" → Slime greift an
  - "Verteidigung!" → Slime blockt
  - "Fähigkeit!" → Slime nutzt Skill
  - "Zurück!" → Slime zieht sich zurück
  - "Heil dich!" → Slime heilt sich (wenn Skill)
  
Najika übersetzt:
  - Spieler ruft "Angriff!"
  - Najika schreit: "GOGO, kleiner Slime! EXPLOSION!!!"
  - Slime führt aus
```

### Fusion (Zukunft)
```yaml
System: 2 Slimes fusionieren [GEPLANT]
Result: Stärkerer Hybrid-Slime
Requirements:
  - Beide Level 50+
  - Beide Slime-Form
  - Kosten: 50.000 Gold

Hybrid-Stats:
  - Average von beiden
  - Kombinierte Skills (bis 30!)
  - Neue Farbe (Mix)
```

## 3. RETTUNGSSCHLEIM (Hardcore Only!)

### Konzept
```yaml
Problem: Hardcore = Permadeath ist hart
Lösung: 1× Rettung pro 24h (IRL!)
Cost: 6 Wochen Grind
```

### Mechanik
```yaml
Rettungsschleim:
  - Verhindert 1× tödlichen Treffer
  - Verfügbar: 1× pro 24h (Real-Time!)
  - Trigger: Automatisch bei HP = 0
  
Effekt:
  - HP wird auf 50% gesetzt
  - 5 Sekunden Unverwundbarkeit
  - Teleport zu Safe Zone (optional)
  
Anzeige:
  - Symbol neben HP-Bar (💚)
  - Wenn verbraucht: Symbol grau (🖤)
  - 24h Countdown-Timer
```

### Grind für volle Ladung
```yaml
Requirement: 6 Wochen Training

Training:
  - Täglich 1 Stunde Slime-Training
  - 42 Tage = 6 Wochen
  - Nach 42 Tagen = Permanent aktiv
  
Ladung:
  - Day 1-14: 0% (noch keine Rettung!)
  - Day 15-28: 50% (50% Chance zu triggern)
  - Day 29-42: 75% (75% Chance)
  - Day 42+: 100% (immer verfügbar!)
  
Reset:
  - Nach jeder Nutzung: 24h Cooldown
  - ABER: Permanent-Status bleibt
  - Kein erneuter 6-Wochen-Grind nötig
```

## 2. BEISPIEL-EVENTS

### Event: Der Bettler
```yaml
Beschreibung:
  Ein alter Mann steht am Wegrand.
  "Bitte, meine Tochter ist krank! Ich brauche 50 Gold für Medizin!"
  
Najika warnt:
  "Wahrscheinlichkeit: 82% Falle, Kuja!"

Optionen:
  [A] Gib 50 Gold
      → Heroisch +15, Chaos -1
      → 20% Chance: Echter Bettler, bekommt Segen (HP +20 permanent!)
      → 80% Chance: Falle, Banditen spawnen!
      
  [B] Gib 20 Gold (Kompromiss)
      → Pragmatisch +10, Chaos 0
      → Mann ist enttäuscht, geht weg
      → Keine Konsequenzen
      
  [C] Begleite ihn
      → Heroisch +20, Chaos -2
      → Quest startet: "Krankes Mädchen heilen"
      → Reward: Rare Item + Friendship
      
  [D] Ignoriere ihn
      → Egoistisch +10, Chaos +1
      → Mann flucht, geht weg
      → Karma -5
      
  [E] Najika entscheidet
      → Najika (Megumin): "EXPLOSION auf den Bettler!"
      → Mann rennt schreiend weg
      → Chaos +5, Bond +5
      → Najika: "Siehst du? Falle! Hehe~"
```

### Event: Die mysteriöse Kiste
```yaml
Beschreibung:
  Eine leuchtende Truhe liegt mitten auf dem Weg.
  Sie pulsiert mit magischer Energie.
  
Najika warnt:
  "Analyse: 82% Falle! Aber... 18% Legendärer Loot! 🤔"

Optionen:
  [A] Öffne sofort
      → Heroisch +5, Chaos +5
      → 40% Trap (Gift-Gas, -50 HP!)
      → 40% Normal Loot (Gold, Items)
      → 18% Legendary Loot (Epic Weapon!)
      → 2% Mimic (Boss-Fight!)
      
  [B] Untersuche erst
      → Pragmatisch +10, Chaos 0
      → Skill-Check: Perception (0-100)
      → Bei >50: Trap erkannt, kann disarmed werden
      → Bei <50: Wie Option A
      
  [C] EXPLOSION!
      → Chaos +20, Bond +10
      → Najika: "EXPLOSION!!!"
      → Truhe zerstört
      → 50% Loot überlebt (beschädigt)
      → 50% Loot komplett zerstört
      → Aber: Garantiert keine Trap!
      
  [D] Ignoriere
      → Pragmatisch +5, Chaos -5
      → Truhe bleibt da
      → Kann später zurückkommen
      
  [E] Najika entscheidet
      → Najika (Shiro): "Berechne..."
      → Führt Analyse durch
      → Ergebnis: Beste Option basierend auf Stats
      → Bond +5
```

### Event: Die betrunkenen Goblins
```yaml
Beschreibung:
  3 Goblins blockieren den Weg.
  Sie sind betrunken und singen lautstark.
  "Hic! Zoll bezahlen! Hic!"
  
Najika kommentiert:
  "Die sind SO betrunken! Das wird lustig! 😜" (Harley)

Optionen:
  [A] Bezahle "Zoll" (10 Gold)
      → Pragmatisch +5
      → Goblins lassen dich durch

  [B] Kämpfe!
      → Heroisch +10, Chaos +10
      → Kampf (3 betrunkene Goblins)
      → Schwäche: Taumeln, langsam
      → Loot: Gold, Alkohol-Items
      
  [C] Trickse sie aus
      → Egoistisch +15, Chaos +5
      → Charisma-Check (0-100)
      → Bei Erfolg: Goblins schlafen ein
      → Bei Fail: Wütend, schwerer Kampf!
      
  [D] Schleiche vorbei
      → Pragmatisch +10, Chaos -5
      → Stealth-Check (0-100)
      → Bei Erfolg: Vorbei ohne Kampf
      → Bei Fail: Überrascht, Kampf!
      
  [E] Najika entscheidet
      → Najika (Harley): "Hehe, lass mich! 😜"
      → Najika tanzt für Goblins
      → Goblins sind abgelenkt
      → Najika stiehlt ihr Gold
      → Goblins merken es nicht
      → Chaos +10, Bond +10, Gold +30!
```
