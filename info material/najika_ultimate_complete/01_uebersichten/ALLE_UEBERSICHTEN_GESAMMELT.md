## 🔍 LESSONS LEARNED (aus allen Chats)

### **Aus "Ollama connection error":**
```
- 404 Error häufig bei falschem Endpunkt
- Endpoint: http://localhost:11434 (NICHT 5000!)
- ollama serve muss laufen
- ollama list → Modelle prüfen
```

### **Aus "Project status and new installation":**
```
- NICHT drauflos coden ohne Analyse
- Funktionierende Teile NUTZEN
- C:\NajikaCore hat viel Working Code
- SimpleHTTPRequestHandler vs Flask: self.path mapping kritisch
- Wände auto-ausrichten Code existiert (finden!)
```

### **Aus "Game design: combat mechanics":**
```
- Opus' najika_server_COMPLETE.py war funktional
- Kätzchen-Trigger für Wizard-Vicuna funktioniert
- 3D Digivice mit KayKit Assets
- Syntax-Fehler durch zu viele Neuversuche
- User-Frustration vermeiden
```

### **Aus "Najika script functionality analysis":**
```
- Sakura = Gothic Lolita (nicht nur Name!)
- 4 Persönlichkeiten durch Megumin-Perspektive
- V3/V4/V5 Dokumentation konsolidieren
- Secure Messenger FEHLT noch!
- Spell Progression: Feuer → Feuga → Feura
```
