# 1️⃣ PROJEKT-IDENTITÄT

## Was ist Najika World?

**Najika World** ist ein **Survival-RPG Tamagotchi-Hybrid** mit einer **AI-Begleiterin namens Najika**.

**Kern-Konzept:**
```
Digimon World (Tamagotchi-Pflege)
  + KonoSuba (Explosion-Klasse, Megumin)
  + Oregon Trail (Event-System)
  + Dark Souls (Combat-Feel)
  + Soulframe (Stamina/Dodge Mechaniken)
  = NAJIKA WORLD
```

## Genre & Stil

**Genre:** Survival-RPG mit Tamagotchi-Elementen
**Setting:** Fantasy-Welt (8 Regionen)
**Perspektive:** Third-Person (über-die-Schulter)
**Plattform:** Browser (jetzt), Android APK (bald), UEFN/Fortnite (später)

```
1. Najika pflegen (Hunger, Energie, Hygiene, Happiness)
```

## 💀 Hardcore/Softy System

### Hardcore-Modus

**Features:**
- **Permadeath** (ALLES WEG bei Tod)
- **Rettungsschleim:** 1x pro 24h (IRL)
- **Totem (Endgame Item):** Verhindert 1x Tod
- **PvP:** "Alles-abgeben-um-zu-leben" Option
- **Najika erscheint beim 1. Tod** (bietet Softy-Wechsel an)

**Tod-Ablauf:**
```
1. Tödlicher Treffer empfangen
2. Totem-Check (falls vorhanden → überlebt)
3. Slime-Check (falls verfügbar, 1x/24h → rettet)
4. Revive-Fenster (8 Sekunden "downed")
   - Team kann wiederbeleben
   - Sonst: Tod

5. Najika erscheint beim ERSTEN Tod:
   "Ohjee... das ist wohl zu hart für dich.
    Komm, ich bringe dich ins sichere Softy-Land."

   Optionen:
     [Ja] → Permanent Softy-Modus
     [Nein] → Hardcore-Regeln greifen (Permadeath)
```

---

### Softy-Modus

**Features:**
- **Kein Permadeath**
- **30 Sekunden Revive-Timer** (statt 8 Sekunden)
- **PvP:** Nur Ranking, KEINE Verluste
- **Normal-PvP verfügbar:** Gewinner wählt 1 Ausrüstungsteil (kein Permadeath)
- **Gäste erlaubt** (Freunde können mitspielen)

**WICHTIGE REGEL:**
- ⚠️ **Einmal Softy = permanent Softy!**
- Keine Rückkehr zu Hardcore möglich
- Entscheidung ist FINAL

---

## ⚔️ PvP-System (3 Modi)

### 1. Hardcore-PvP

**Ablauf bei Niederlage:**
```
Phase 1 - Lethaler Treffer:
  → Verteidiger KANN "Alles-abgeben-um-zu-leben" anbieten
  → Timeout: 30 Sekunden

  Optionen:
    A) "ALLES GEBEN um zu LEBEN" (Mercy anbieten)
    B) "Kämpfe bis zum Tod" (Permadeath akzeptieren)

Phase 2 - Angreifer-Entscheidung (wenn A gewählt):
  → Angreifer KANN Mercy akzeptieren oder ablehnen
  → Timeout: 30 Sekunden

  Optionen:
    A) "GNADE GEWÄHREN" (Items erhalten, Ehre-Bonus)
    B) "KEINE GNADE" (Gegner stirbt permanent)

Phase 3 - Double-Confirmation (wenn Gnade gewährt):
  → Verlierer muss 2x "JA" tippen

  Bestätigung 1:
    "⚠️ BESTÄTIGUNG 1/2 ⚠️
     Du wirst ALLES verlieren:
     - X Ausrüstungsteile
     - X Inventar-Items
     - 7 Tage PvP-Sperre

     LETZTE CHANCE!
     Dies ist FINAL und kann NICHT rückgängig gemacht werden!

     Tippe nochmal 'JA' um ENDGÜLTIG zu bestätigen."

Phase 4 - Item-Transfer:
  → ALLES wird übertragen (KEINE AUSNAHMEN!)
  → Verlierer erhält 7 Tage PvP-Sperre
  → Verlierer bleibt mit NICHTS zurück
```

**🚨 KRITISCHE REGEL: "ALLES WEG = ALLES WEG!"**
```
FALSCH ❌:
  - "Spieler behält Starter-Waffe"

RICHTIG ✅:
  - ABSOLUT ALLES wird übertragen
```

## 🐌 Slime-Begleiter-System

**Kern-Konzept:** Tamagotchi-artiger Begleiter

### Basics

**Slime-Farben (8):**
- Jede Region hat eigene Farbe
- Crimson → Rot
- Emerald → Grün
- Azure → Blau
- Golden → Gelb
- Shadow → Schwarz
- Crystal → Weiß
- Violet → Lila
- Amber → Orange

**Erwerb:**
- 1. Slime: Tutorial/Quest (kostenlos)
- Weitere: Finden, kaufen, züchten

---

### Tamagotchi-Pflege

**Needs (wie Najika):**
- Hunger (0-100)
- Energy (0-100)
- Hygiene (0-100)
- Happiness (0-100)

**Folgen bei Vernachlässigung:**
- Stats sinken
- Slime wird schwächer im Kampf
- Metamorphose verlangsamt sich
- Bei 0% Happiness: Läuft weg! (PERMANENT verloren!)

---

### Metamorphose-System

**Tier-System:**
```
Baby (Level 1) → Kind (Level 10) → Jugend (Level 25) → Erwachsen (Level 50)
```

**Beeinflusst durch:**
- Futter-Art (Fleisch → Krieger, Gemüse → Heiler, etc.)
- Training-Art (Combat → Kampf-Form, Magie → Mage-Form)
- Najika's Einfluss (10-15% Übernahme ihrer Persönlichkeit)

**Beispiel:**
```
Slime füttert Fleisch + trainiert Combat + Najika ist im Megumin-Mode
  → Entwickelt sich zu "Explosion Slime" (Megumin-inspiri ert!)
```

---

### Rettungs-Mechanik (Hardcore)

**Funktion:**
- 1x pro 24h (IRL) kann Slime den Spieler retten
- Cooldown: 24h ab letzter Rettung
- Slime muss bei Spieler sein (nicht im Lager!)
- Wenn Cooldown läuft: KEIN Schutz!

**Ablauf:**
```
Spieler erhält tödlichen Treffer
  → Slime springt vor
  → Spieler überlebt
  → Slime: -50% HP
  → Cooldown startet (24h)
```

---

### Kampf-Modi (4)

**1. Passiv (Default):**
- Slime macht nichts (bleibt im Hintergrund)

**2. Defensiv:**
- Slime blockt Angriffe
- Zieht Aggro von Spieler

**3. Offensiv:**
- Slime greift eigenständig an
- Nutzt eigene Skills

**4. Unterstützung:**
- Slime heilt/buffed Spieler
- Sammelt Items während Kampf

---

**Konzept:**
- Slime lernt von Najika's Persönlichkeit
- 10-15% ihrer aktuellen dominanten Persönlichkeit

### Cheer-System (Digimon World)

**Konzept:**
- Spieler kann Najika/Slime **anfeuern** während Kampf
- Erhöht Stats temporär
- Motivations-Boost

**Commands:**
```
[Anfeuern] → +10% Angriff (10 Sekunden)
[Verteidigen] → +20% Verteidigung (10 Sekunden)
[Heilen] → +5% HP Regen (30 Sekunden)
[Magie] → +10% Magie-Schaden (10 Sekunden)
```

---

### Skill-Weaving (Final Fantasy)

**Konzept:**
- Skills kombinieren für stärkere Effekte

**Beispiel (Feuer-Magie):**
```
Fire (Level 1) → 50 Schaden, Single-Target
  ↓ kombiniere 2x Fire
```
