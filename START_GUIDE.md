# 🚀 NAJIKA WORLD - START GUIDE

**Du hast jetzt 4 verschiedene Start-Optionen!**

---

## 🎮 NUR GAME (ohne Backend)

### Option 1: Phase 1 (Flat - Empfohlen!)
```bash
START_NAJIKA_PHASE1_FLAT.bat
```
**Features:**
- ✅ Flat Terrain (stabil, getestet)
- ✅ Beste Performance
- ✅ Alle Game-Features
- ✅ Keine Backend-Features (Chat, Voice, etc.)

### Option 2: Phase 2 (Terrain - Experimentell)
```bash
START_NAJIKA_PHASE2_TERRAIN.bat
```
**Features:**
- 🏔️ Terrain Variation (Berge, Täler)
- 🌳 Vegetation System
- 🎨 LOD System
- ⚠️ Experimentell! Kann laggy sein
- ✅ Keine Backend-Features

---

## 🎮 GAME + BACKEND (mit Chat, Voice, etc.)

### Option 3: Phase 1 + Backend (Empfohlen!)
```bash
START_NAJIKA_PHASE1_FULL.bat
```
**Features:**
- ✅ Flat Terrain (stabil)
- ✅ Backend Online (Port 8000)
- ✅ Najika AI Chat
- ✅ Teleport System
- ✅ Stats Sync
- ✅ Voice Call (falls TTS)

### Option 4: Phase 2 + Backend (Experimentell)
```bash
START_NAJIKA_PHASE2_FULL.bat
```
**Features:**
- 🏔️ Terrain Variation
- ✅ Backend Online
- ✅ Alle Backend-Features
- ⚠️ Experimentell!

---

## 🐛 PROBLEME?

### Phase 2 lädt nicht / Error:
→ Nutze Phase 1 stattdessen!
→ Phase 2 braucht GPU Power

### Backend startet nicht:
→ Prüfe ob Python + Dependencies installiert sind
→ Oder nutze "_FLAT.bat" / "_TERRAIN.bat" (ohne Backend)

### Port schon belegt:
→ Schließe andere Najika-Fenster
→ Oder ändere Port in BAT-Datei

---

## 🔄 ZWISCHEN MODI WECHSELN

Du kannst jederzeit zwischen Phase 1 und Phase 2 wechseln:

1. **Stop** aktuelles Game (CTRL+C)
2. **Start** andere BAT-Datei
3. **Fertig!** Die BAT setzt automatisch den richtigen Modus

---

## 📋 CONTROLS (beide Modi gleich)

- **WASD** - Movement
- **Shift** - Sprint
- **E** - Interact (Mühle/Städte)
- **Tab** - Combat Mode
- **Q,E,Space,C,X,V** - Combat Actions
