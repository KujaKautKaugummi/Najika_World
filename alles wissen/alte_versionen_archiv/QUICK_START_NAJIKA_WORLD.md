**Stand:** 2025-11-02 (SOFORT einsatzbereit!)

## 🚀 SCHNELLSTART (3 Schritte)

### **1. INSTALLER AUSFÜHREN:**
```
Rechtsklick auf Desktop\NAJIKA_WORLD_INSTALLER_FINAL.bat
→ Als Administrator ausführen
```

Wartet 2-3 Minuten während NajikaFinal kopiert wird.

### **2. NPM INSTALL:**
```cmd
cd C:\Najika-World\frontend
npm install
```

Wartet 2-3 Minuten während Node Modules installiert werden.

### **3. STARTEN:**
```
Desktop: Doppelklick "Najika World"

ODER:

cd C:\Najika-World
START_NAJIKA_WORLD.bat
```

Browser öffnet automatisch: http://localhost:3002

## ✅ WAS DU SEHEN SOLLTEST:

### **Browser:**
- 🗺️ **Grüner Boden** (2400x2400 Map)
- 🏰 **6 braune Cubes** (Gebäude-Placeholder)
- 💗 **Pinke Kapsel** (Najika Character)
- 🌤️ **Himmel + Sonne**
- 📊 **Debug Info** (oben rechts)

### **Steuerung:**
- **W/A/S/D** - Laufen
- **Shift** - Rennen
- **Lauf zu einem Cube** → "E - Gebäude betreten" Button erscheint
- **Klick Button** → Wechsel zu Raum

### **Im Raum:**
- **W/A/S/D** - Laufen
- **Exit to World Button** (unten rechts)

## 🐛 FALLS FEHLER:

```cmd
cd C:\Najika-World\frontend

```

### **"Backend not connected":**
```cmd
cd C:\Najika-World\backend
python najika_server.py
```

### **Port 3002 belegt:**
```cmd
# Töte alte Node Prozesse:
taskkill /F /IM node.exe
```
