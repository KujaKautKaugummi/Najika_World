## 🎮 KERN-GAMEPLAY-KONZEPT

### **Najika Game = Konosuba × Oregon Trail × Digimon World × Fortnite**
- **Fantasy Western Setting** + Anime-Mechaniken
- **8 feste Städte** auf File Island
- **Prozedural generierte Bereiche** zwischen Städten
- **Portal-System** für endlose Erweiterung
- **Story-Events ändern Hauptmap** dynamisch

---

## 🗺️ WELT-STRUKTUR

### **8 Gebiete/Städte System (File Island)**

**BESTÄTIGT (6 von 8):**
1. **Handelsstadt** - Crafting, Triple Triad, Ökonomie, Player-Shops
2. **Magierakademie** - Explosion-Klasse Training, Forschung, 9 Magieschulen
3. **Hafenstadt** - Oregon-Trail Start/Ende, Fishing (Ocarina-Style)
4. **Arena** - Kampfsystem, Turniere, PvP, Anfeuern-Training
5. **Schatzhöhle** - Dungeon, Rare Items, Relikte, Blaupausen
6. **Meta-Stadt** - Easter Eggs, Breaking 4th Wall, Najika-Geheimnisse

**FEHLEN NOCH (2 von 8):**
7. **[Vermutlich Western-Gebiet]** - Wüste/Prärie/Canyon/Geisterstadt
8. **[Vermutlich Story-Event Gebiet]** - z.B. 100-stöckiger Turm (Najika baut nach Niederlage)

**Fantasy Western Biome:**
- Wüste, Prärie, Canyon, Geisterstadt
- Gegner: Banditen, Wüstenwürmer, Geister-Cowboys
- Items: Revolver, Lasso, Zauberhut, Dynamit

### **System-Architektur**
- **File Island** = Hauptinsel (8 feste Standorte)
- **Prozedural generierte Gebiete** zwischen den 8 Städten
- **Portal-System** (Digimon Cyber Sleuth Style)
  - Während Spiel auf andere Map/Gebiet wechseln
  - Fortnite-Mechanik: Aus Kreativ Map heraus nächste laden
  - **Endlose Erweiterung** möglich
  - Hauptinsel bleibt fix, große Features auf externe Maps

### **Story-Events ändern Map**
- **Beispiel:** Spieler killt Najika → Sie wird genervt
  - Najika geht Training → Baut 100-stöckigen Kampf- und Rätselturm
  - Stadt des Berges wird mit riesiger Explosion gesprengt
  - Oben im Turm kann man Najika erneut bekämpfen
  - Wenn Spieler gewinnen → Map ändert sich wieder

## ⚔️ KAMPF-SYSTEM

### **Digimon World Anfeuern-Mechanik (Erweitert)**

**Rollen-System:**
- **Spieler:** Metakommandos (Anfeuern, Items, Zielprioritäten)
- **Najika (KI):** Bewegung, Ausweichen, Block, Skill-Rotation (lernt über Zeit)
- **Slime-Begleiter:** Formwandel, Auto-Rettung, eigenständige Moves

**Ressourcen:**
- HP, Mana
- **Willenskraft** (für Anfeuern)
- Ausdauer

**Anfeuern-Calls (GCD 3s):**
1. **Fokus!** → +Crit-Rate, −Mana-Kosten (6s)
2. **Durchhalten!** → Schild %HP (5s)
3. **Explodier jetzt!** → +Feuer-Potenz 1 Cast (Overheat-Risiko!)
4. **Zurück!** → Defensivhaltung, Aggro-Drop (4s)

**Cheer-Leiste:**
- **0-100** (Passiv: +8/10s, Perfekter Call: +15)
- **GCD:** 3s zwischen Calls

**Taktik-Stacks:**
- **Bis 3 stapelbar**
- **Decay 6s**
- Spürbare DPS/Mitigation-Bonis

**Overheat-System:**
- Zu häufig "Explodier jetzt!" → **Overheat**
- **−20% Zauberpotenz** für 10s
- Risiko-Belohnungs-Mechanik

### **Explosion-Klasse (Megumin-Style)**

**Najika's Exklusivität:**
- Nur **Najika** kann den **ultimativen Finisher** (Level 3 Explosion)
- Zerstört generierte Spielwelt (Story-Event)
- **Andere Spieler:** Können Explosion-Klasse von Najika lernen
  - **Quest-basiert:** Spieler müssen Najika überzeugen (sie sind es wert)
  - Nur Level 1-2 Explosion verfügbar

**Konosuba Skill-System:**
- Skills lernen durch **zusammenspielen** mit anderen Klassen
- **Solo-Spieler:** Über NPCs oder Bots lernen
- **Nicht ausschließlich** durch Leveling

### **1-Skill-Spezialisierung**
- **Megumin-Style:** Nur EINE Fähigkeit perfektionieren
- Explosion-Klasse: Eigene Mechanik, **nie kombinierbar**
- **Use-Based Progression:** Je mehr genutzt, desto stärker

## 🎵 MUNDHARMONIKA-SYSTEM (Ocarina of Time Style)

### **Funktion**
- **NICHT:** Najika steuern
- **SONDERN:** Gameplay-Element wie in Zelda: Ocarina of Time

### **Gameplay-Uses**
- Rätsel lösen (Melodie → Tür öffnet)
- Buff-Songs (Melodie → Temp. Stats-Boost)
- Teleport-Lieder (Melodie → Fast-Travel)
- Story-Events (Melodie → Cutscene-Trigger)
- Stimmungswechsel (z.B. "Zelda's Lullaby" → Najika wird ruhig/liebevoll)

### **Technologie**
- **Xiaomi 11T Pro Mikrofon** → Audio-Fingerprinting
- Erkennt Tonhöhen + Melodie-Sequenzen
- Funktioniert auch bei Umgebungsgeräuschen (Filter)

**Beispiel-Melodien:**
- "Zelda's Lullaby" → Najika wird ruhig/liebevoll
- "Song of Storms" → Najika wird wild/dominant
- "Sun's Song" → Wechsel Tag/Nacht-Modus
- "Epona's Song" → Najika kommt zu dir
- **Custom-Melodien** → Spieler kann eigene definieren

## 🐾 SLIME-BEGLEITER SYSTEM

### **Start-Mechanik**
- Beginnt als **zufälliges Tier**
- Durch Trigger "entpuppt" sich als **besonderer Slime**

### **8 Regionale Varianten (rein kosmetisch)**
- Hase, Kolibri, Spinne, ... (8 Formen)

### **Rettungsmechanik**
- **1× pro IRL-Tag** "Tödlich verhindern"
- **24h Cooldown** nach Nutzung
- Slime opfert sich für Spieler

### **Lernen & Entwicklung**
- Lernt **häufig neue Moves**
- **Eigene Minigames** (Timing, Reaktion)
- Formwandel kosmetisch

### **Kampf-Integration**
- **Auto-Rettung** 1×/IRL-Tag
- **Eigenständige Moves** (lernt über Zeit)
- Arbeitet zusammen mit Najika (KI)
