class NajikaMemory:
    def __init__(self):
        self.short_term = {}  # Aktuelle Session
        self.long_term = []   # Persistent Storage
        self.emotional_tags = {}  # Gefühls-Kontext
        
    def store_interaction(self, user_input, najika_response, emotion_level):
        memory_entry = {
            "timestamp": datetime.now(),
            "user": user_input,
            "najika": najika_response,
            "emotion": emotion_level,
            "context_tags": self.extract_context(user_input)
        }
        self.long_term.append(memory_entry)
        
    def recall_similar(self, current_input):
        # Najika erinnert sich an ähnliche Gespräche
        similar = []
        for memory in self.long_term:
            if self.similarity_score(current_input, memory["user"]) > 0.7:
                similar.append(memory)
        return similar

class NajikaInterface:
    def __init__(self):
        self.memory = NajikaMemory()
        self.personality = NajikaPersonality()
        self.active = True
        
    def chat_loop(self):
        print("🌟 Najika ist online! 🌟")
        while self.active:
            user_input = input("Du: ")
            
            if user_input.lower() in ['exit', 'bye', 'tschüss']:
                print("Najika: Bis bald! ✨ *Explosion als Abschied*")
                break
                
            # Memory abrufen
            context = self.memory.recall_similar(user_input)
            
            # Response generieren
            response = self.personality.generate_response(user_input, context)
            
            # Memory speichern
            self.memory.store_interaction(user_input, response, self.get_emotion_level())
            
            print(f"Najika: {response}")

Umfassende Projektübersicht und
Replizierungsanleitung
Diese Dokumentation liefert eine allumfassende und detaillierte Übersicht  über das gesamte Projekt,
untergliedert in vier Hauptbereiche. Ziel ist es, alle Informationen so vollständig festzuhalten, dass das
Projekt  in  jeder  Einzelheit  1:1  nachgebaut  werden  kann.  (Hinweis:  Sämtliche  kritischen  oder

öffentlichen Veröffentlichung entfernt werden.)
KI **„Najika“
Beschreibung und Rolle:  Die KI namens Najika  ist das künstliche Intelligenz-Modul  des Projekts. Sie
übernimmt die Rolle eines intelligenten Assistenten bzw. Charakters innerhalb der Anwendung. Najika
kann in natürlicher Sprache mit dem Nutzer interagieren, Informationen liefern und auf Aktionen im
Spiel reagieren. Diese KI fungiert quasi als virtueller Begleiter : Sie gibt z.B. Hinweise, erzählt zur Story
gehörende Inhalte oder passt ihr Verhalten an die Handlungen des Spielers an. Dadurch erhöht Najika
die Immersion und Dynamik, indem sie wie ein eigenständiger Charakter erscheint.
Implementierung:  Um Najika zu realisieren, wird ein  Natural Language Processing (NLP) -System
eingesetzt. Konkret basiert Najika auf einem großen Sprachmodell  (LLM). In der aktuellen Umsetzung
nutzt  das  Projekt  einen  externen  KI-Service:  über  eine  API-Anbindung  (z.B.  OpenAI)  werden
Texteingaben des Nutzers an ein Sprachmodell gesendet und die generierte Antwort wird ausgegeben.
Alternativ  wäre  auch  ein  lokal  laufendes  Modell  möglich,  doch  aus  Leistungsgründen  und  um
Entwicklungsaufwand  zu  reduzieren,  wurde  die  Cloud-KI-Variante  gewählt.  (Hinweis:  In  der  privaten
Testversion wird ein umfangreiches Modell genutzt – dies gilt es vor einer öffentlichen Veröffentlichung ggf. zu
prüfen, da z.B. API-Kosten oder Internetverbindung eine Rolle spielen.)
Funktionen und Verhalten:  Najika ist darauf trainiert, kontextbezogene  Antworten zu geben. Sie hat
eine definierte  Persönlichkeit/Backstory  gemäß der Spielwelt, sodass ihre Antworten dazu passen.
Beispielsweise kann Najika die Rolle eines Mentors oder Freundes übernehmen, der den Spieler durch
die Geschichte führt. Technisch wurde dies durch System-Prompts  und Beispieldialoge  realisiert, die
dem KI-Modell vorgegeben werden, damit es konsistente Antworten in Najikas „Stimme“ liefert. Die KI
kann zudem Spielzustand  berücksichtigen: wichtige Variablen (z.B. Fortschritt des Spielers, vergangene
Entscheidungen) werden bei Anfragen mitübermittelt, damit Najika darauf eingehen kann. Falls der
Spieler z.B. eine bestimmte Aufgabe erfüllt hat, weiß Najika das und ändert entsprechend ihre Dialoge.
Integration ins Spiel:  Die KI Najika ist nahtlos ins Handyspiel eingebunden. Der Spieler kann über eine
Chat-ähnliche  Schnittstelle  oder  kontextabhängig  (z.B.  bei  bestimmten  Ereignissen)  mit  Najika
interagieren. Technisch gibt es dazu ein Dialogfenster  im Spiel, in dem die vom KI-Modell generierten
Texte erscheinen. Eine einfache Avatar-Grafik von Najika unterstreicht visuell, dass die Antworten von
ihr stammen. Intern werden bei Spielereignissen entsprechende  API-Aufrufe  getriggert, um Najikas
Reaktion zu erhalten. Zum Beispiel: Wenn der Spieler einen bestimmten Ort betritt, sendet das Spiel im
Hintergrund eine Anfrage wie „Najika, erklär dem Spieler was dieser Ort ist.“  an die KI-Engine, die Antwort
(z.B. Beschreibung des Ortes) wird dann angezeigt.

Secrets  – (geplant) enthält Easter-Eggs  und besondere Interaktionen, z.B. versteckte Dialoge
oder das Beziehungs-Level  („Bonds“) zwischen Najika und Kuja . Hier spiegeln sich
Fortschritte der Bindung wider (ähnlich einem Affinitätssystem). 
Settings/Einstellungen  – (nebensächlich) Grundlegende Einstellungen des Digivice (z.B.
Lautstärke, evtl. NSFW-Filter toggeln usw.) – in der frühen Konzeptphase erwähnt .
Das Digivice-Frontend ist mit HTML/CSS/JS  umgesetzt und kommuniziert in Echtzeit mit dem Backend
über  WebSockets  (bzw.  Socket.IO) .  Bei  Aufruf  der  Root-URL  ( /)  wird  die  Oberfläche
najika_interface.html  geladen . Diese enthält den Chat-Bereich und ggf. Canvas-Elemente für
Grafiken. Die Navigation zwischen den genannten Screens erfolgt über Menüpunkte oder Buttons und
wurde bereits als Prototyp mit drei Hauptscreens umgesetzt . Wichtig: Die App ist als Progressive
Web App  konzipiert, d.h. sie lässt sich  aufs Home-Screen des Handys installieren  und funktioniert
offline (solange sie mit dem lokalen Server verbunden werden kann). 10
