# 🎮 PERK-SYSTEM FÜR NAJIKA WORLD - KONKRETE BEISPIELE

## Kernfrage: Brauchen wir Perks überhaupt?

**Das haben wir BEREITS:**
- ✅ Skyrim Learning by Doing (Skills leveln durch Nutzung)
- ✅ Skill-Morphs (1-Skill-Weg)
- ✅ Slime-Boni (passiv durch Begleiter)
- ✅ Oregon Trail Events (Survival-Situationen)

**Was Perks ZUSÄTZLICH bringen könnten:**
- Permanente kleine Boni die den Spielstil personalisieren
- Belohnung für Level-Ups
- Mehr Build-Vielfalt

---

## 🤔 OPTION 1: KEINE separaten Perks

**Stattdessen:** Alles über bestehende Systeme

| Was in Fallout ein Perk ist | In Najika World |
|----------------------------|-----------------|
| "Kopfschütze" (+Headshot DMG) | Precision-Skill leveln (bereits da!) |
| "Explosions-Meister" | 1-Skill-Weg Explosion Morphs |
| "Handelstalent" | Ruf bei Handelsgilde + Charisma |
| "Schnellläufer" | Agility-Stat + leichte Rüstung |
| "Companion-Buff" | Slime-Evolution + Synthese |

**Vorteil:** Weniger kompliziert, nutzt bestehende Systeme
**Nachteil:** Weniger Anpassungsmöglichkeiten bei Level-Up

---

## 🎯 OPTION 2: Perks ALS TEIL der Skill-Linien

Perks sind keine separaten Punkte, sondern **automatisch bei Skill-Meilensteinen**:

### Beispiel: Feuer-Magie Skill-Linie

```
Level 10: "Flammenresistenz"
  → -10% Feuerschaden den du nimmst

Level 25: "Heißer Stahl"
  → Feuerwaffen-Kombos +15% Schaden

Level 50: "Phönix-Funken"
  → 5% Chance bei Tod: 1x wiederaufstehen mit 10% HP

Level 75: "Inferno-Meister"
  → Feuer-Verweben +30% Effekt

Level 100: "Avatar des Feuers"
  → Passive Feuer-Aura, Gegner nehmen DoT in Nähe
```

### Beispiel: Schwert Skill-Linie

```
Level 10: "Schneller Hieb"
  → Erste Attacke nach Sprint +20% Schaden

Level 25: "Parade-Meister"
  → Perfekter Block = Gegner staggert

Level 50: "Kreuzschnitt"
  → Neue Kombo freigeschaltet (X-Slash)

Level 75: "Klingentänzer"
  → Ausweichen während Angriff möglich

Level 100: "Schwertmeister"
  → Alle Schwert-Attacken +25% Crit-Chance
```

### Beispiel: Explosion (1-Skill-Weg)

```
Level 10: "Stabiler Kern"
  → -10% Mana-Kosten

Level 25: "Kettenreaktion"
  → 15% Chance auf zweite Mini-Explosion

Level 50: "EXPLOSION!"
  → Erste Morph-Wahl freigeschaltet

Level 75: "Mega-Detonation"
  → AoE-Radius +50%

Level 100: "Explosions-Legende"
  → Finisher-Cooldown -6 Stunden
  → (Najika exklusiv: Omega-Detonation)
```

**Vorteil:** Perks fühlen sich verdient an, kein extra System
**Nachteil:** Weniger Wahlfreiheit

## 🐾 OPTION 3: Slime-Perks statt Spieler-Perks

Die SLIMES haben Perks die auf dich wirken!

### Beispiel: Moos-Schleim (Samtmoos-Tiefwald)

```
Baby:     "Naturfreund" → +5% Kräuter-Funde
Kind:     "Waldläufer" → Kein Verirren im Wald
Reif:     "Gift-Resistenz" → -20% Giftschaden
Champion: "Regeneration" → +10% HP-Regen außerhalb Kampf
Ultimativ: "Eins mit Natur" → Tiere greifen nicht an
```

### Beispiel: Magma-Schleim (Magmaströme)

```
Baby:     "Wärme" → Kein Kälteschaden
Kind:     "Feuerschutz" → -15% Feuerschaden
Reif:     "Schmelzpanzer" → +10% Rüstung
Champion: "Lava-Blut" → Angreifer nehmen 5 Feuerschaden
Ultimativ: "Vulkan-Herz" → Explosion-Skills +20%
```

### Beispiel: Kristall-Schleim (Tiefenhöhlen)

```
Baby:     "Glitzern" → +10% Gold-Funde
Kind:     "Edelstein-Spürer" → Seltene Erze markiert
Reif:     "Harter Kern" → +15% Stagger-Resistenz
Champion: "Prisma" → Licht-Magie +15%
Ultimativ: "Diamant-Seele" → 1x pro Tag: Tödlicher Schlag = 1 HP
```

**Vorteil:** Motiviert Slime-Pflege, einzigartig für Najika
**Nachteil:** Ohne Slime = keine Perks

## 🎲 OPTION 4: Oregon Trail Events GEBEN Perks

Permanente Perks durch wichtige Entscheidungen!

### Beispiel: "Kannibalismus-Event"

**Situation:** Du findest Überlebende die Menschenfleisch essen

**Optionen:**
1. **Mitmachen** → Perk "Überlebensinstinkt"
   - +20% länger ohne Essen
   - -30 Ruf bei allen Fraktionen
   - Manche NPCs reden nicht mehr mit dir

2. **Ablehnen** → Perk "Ehrenhafte Seele"
   - +10 Ruf bei allen Fraktionen
   - Keine Survival-Boni

3. **Sie töten** → Perk "Richter"
   - +15% Schaden gegen Kannibalen-Feinde
   - "Wilde" Fraktionen hassen dich

### Beispiel: "Der kranke Händler"

**Situation:** Ein Händler ist schwer krank, du hast Medizin

**Optionen:**
1. **Heilen** → Perk "Heiler-Ruf"
   - Händler verkauft dir exklusive Items
   - Handelsgilde +20 Ruf

2. **Ignorieren** → Kein Perk
   - Händler stirbt
   - Sein Sohn hasst dich (Nemesis!)

3. **Bestehlen** → Perk "Skrupellos"
   - Einmaliger Loot
   - Karma -50, Bounty in der Region

### Beispiel: "Der verfluchte Altar"

**Situation:** Ein Altar bietet Macht für einen Preis

**Optionen:**
1. **Annehmen** → Perk "Dunkler Pakt"
   - +25% Dunkel-Magie
   - -25% Licht-Magie (permanent!)
   - Licht-Fraktion hasst dich

2. **Zerstören** → Perk "Lichtbringer"
   - +25% Licht-Magie
   - Dunkel-Magie -25%
   - Dunkel-Fraktion = Feinde

3. **Ignorieren** → Perk "Neutralist"
   - +10% alle Magie
   - Keine Fraktions-Effekte

**Vorteil:** Perks haben Story-Bedeutung, Konsequenzen
**Nachteil:** Verpasste Events = verpasste Perks

## 📊 MEINE EMPFEHLUNG

**Kombination aus Option 2 + 3 + 4:**

```
SPIELER-PERKS:
├── Automatisch bei Skill-Meilensteinen (Level 10/25/50/75/100)
├── Kein Perk-Punkte-System
└── Fühlt sich verdient an

SLIME-PERKS:
├── Passive Boni basierend auf Slime-Typ + Evolution
├── Motiviert Slime-Pflege
└── Einzigartig für Najika World

STORY-PERKS:
├── Permanente Effekte durch Oregon Trail Events
├── Konsequenzen für Entscheidungen
└── Replay-Value (andere Perks bei anderen Entscheidungen)
```

## 🎯 ZUSAMMENFASSUNG

**Perks in Najika World = 3 Quellen:**

1. **Skill-Meilensteine** (automatisch beim Leveln)
2. **Slime-Evolution** (durch Pflege)
3. **Oregon Trail Events** (durch Entscheidungen)

**KEIN separates Perk-Punkte-System!**

Das hält den Kern des Spiels:
- Skyrim Freedom ✅
- Konsequenzen matter ✅
- Slimes sind wichtig ✅
- Nicht überladen ✅
