## 1. DAS KONZEPT: ESKORTE-DIENST

### Was Söldner SIND:

```yaml
SÖLDNER = BODYGUARDS FÜR DEN WEG

SIE TUN:
├── Begleiten durch gefährliche Routen
├── Schützen vor ALLEN Gegnern unterwegs (auch harte!)
├── Bringen dich sicher von A nach B
├── Warten am Dungeon-Eingang
└── Bringen dich auch ZURÜCK (wenn bezahlt)

SIE TUN NICHT:
├── ❌ Boss-Kämpfe mitmachen
├── ❌ Dungeon-Kammern räumen
├── ❌ Quest-Ziele erledigen
├── ❌ Mit dir zusammen trainieren
└── ❌ Teamkampf (DAS MUSST DU LERNEN!)
```

### Warum so?

```
Du willst zum Dungeon Kammer 2 aber der Weg ist zu hart?
→ Söldner bringt dich HIN
→ Du kämpfst in der Kammer ALLEINE
→ Söldner bringt dich ZURÜCK (extra Kosten)

= Du brauchst trotzdem SKILL für den eigentlichen Content!
= Söldner sind keine Abkürzung zum Sieg!
```

## 3. DIENSTE & KOSTEN

### 3.1 ESKORTE BILLIG (AI-Abbilder)

```yaml
WAS:
- AI-Abbild eines Besungenen begleitet dich
- Kämpft gegen ALLE Gegner unterwegs (auch harte!)
- Stoppt am Ziel (Dungeon-Eingang, Boss-Raum, etc.)
- IMMER verfügbar (keine echten Spieler nötig)

KOSTEN:
├── Stufe 2 Abbild: 300 Gold (Hin)
├── Stufe 2 Abbild: 500 Gold (Hin + Zurück)
├── Stufe 3 Abbild: 600 Gold (Hin)
├── Stufe 3 Abbild: 1000 Gold (Hin + Zurück)
└── Pro Gebiet/Zone

VORTEILE:
+ Immer verfügbar
+ Günstiger
+ Keine Wartezeit

NACHTEILE:
- Schwächer als echte Spieler
- Keine Rettung möglich
- Weniger flexibel (folgt festen Routen)
```

### 3.2 ESKORTE PREMIUM (Echte Spieler)

```yaml
WAS:
- Ein ECHTER Spieler begleitet dich live
- Kämpft gegen ALLE Gegner unterwegs
- Kann flexibel reagieren
- Deutlich stärker als AI

KOSTEN:
├── Stufe 2 Echt: 800 Gold (Hin)
├── Stufe 2 Echt: 1200 Gold (Hin + Zurück)
├── Stufe 3 Echt: 1500 Gold (Hin)
├── Stufe 3 Echt: 2500 Gold (Hin + Zurück)
└── Pro Gebiet/Zone

VORTEILE:
+ Stärkerer Schutz
+ Flexibler (echte Entscheidungen)
+ Kann improvisieren

NACHTEILE:
- Muss online + verfügbar sein
- Teurer
- Wartezeit möglich
```

### 3.3 RETTUNG (NUR echte Spieler!)

```yaml
WAS:
- Du bist gestorben
- Ein ECHTER Spieler (Legendär-Rang) kommt
- Birgt deinen Körper, du behältst Items

WICHTIG:
├── ❌ KEINE AI-Rettung!
├── ✅ NUR echte, aktive Spieler
├── Muss sich erst Community aufbauen!
└── Am Anfang: Sehr selten verfügbar

KOSTEN:
- 5000 Gold ODER seltenes Item
- Legendär-Söldner bekommt 80% davon

LIMITIERUNG:
- Max 1 Rettung pro Tag (Echtzeit)
- Söldner muss online + verfügbar sein
- Im Kampfturm: KEINE Rettung möglich
```

## 4. LIVE-SÖLDNER SYSTEM

### NUR Echte Spieler!

```yaml
WARUM NUR ECHT:
├── Muss sich organisch aufbauen
├── Community-Interaktion fördern
├── Keine AI-Abkürzungen
└── Echtes Hardcore-Feeling

WIE ES FUNKTIONIERT:

ALS SÖLDNER VERFÜGBAR MELDEN:
1. Gehe zur Söldner-Gilde
2. "Als Eskorte verfügbar"
3. Wähle: Welche Gebiete du kennst
4. Warte auf Anfragen

WENN ANFRAGE KOMMT:
1. Popup: "[Spieler] braucht Eskorte nach [Ziel]"
2. Annehmen → Teleport zu ihm
3. Job machen → Gold kassieren
4. Zurück in deine Welt
```

### Söldner-Tod

```yaml
WENN DU ALS SÖLDNER STIRBST:
├── Zurück in deine Welt (kein Perma-Tod)
├── 10% Gold-Verlust
├── 2h Debuff (kann nicht dienen)
└── Auftraggeber: Kein Refund, muss neuen rufen

WENN AUFTRAGGEBER STIRBT:
├── Söldner-Job endet
├── Du bekommst trotzdem bezahlt
└── Sein Tod = sein Problem
```

## 6. TECHNISCHE ANFORDERUNGEN

### Lag-freies Gameplay

```yaml
MASSNAHMEN:

1. OFFLINE-FIRST
   ├── Kampf läuft lokal
   ├── Server nur für Sync
   └── Kein Lag = Kein Problem

2. CLIENT-AUTHORITY (für Combat)
   ├── Client entscheidet Hits
   ├── Server validiert nachträglich
   └── Keine Rollbacks im Kampf

3. GRACEFUL DISCONNECT
   ├── Bei Verbindungsverlust: Pause
   ├── Spiel wartet auf Reconnect
   └── Max 30 Sekunden

4. PREDICTIVE ENEMY AI
   ├── Gegner-Moves lokal berechnet
   ├── Server-Sync im Hintergrund
   └── Keine "Teleporting Enemies"
```
