## 🎥 ORBIT CAM - TAMER-MODUS (Digimon World Style)

### **WAS IST DAS?**
Du bist der **Trainer**, Najika kämpft **autonom**.
Du gibst **Befehle/Signale**, sie führt aus (oder ignoriert, je nach Discipline).

### **EVOLUTION SYSTEM:**
```
ROOKIE (0-100 XP):
├─ Direkte Commands (ATTACK/DEFEND/TECH/DISTANCE)
├─ Najika folgt blind (wenn Discipline hoch)
└─ Wie Digimon World 1 Original

CHAMPION (100-500 XP):
├─ Taktische Vorschläge
├─ Najika wählt selbst WIE
└─ Timing-Bonus aktiviert

ULTIMATE (500-1000 XP):
├─ Strategische Richtung (OFFENSIVE/DEFENSIVE)
├─ 90% autonom
└─ Lernt deine Präferenzen

MEGA (1000+ XP):
├─ Übergeordnete Signale (NOW!/WAIT!)
├─ 100% autonom
└─ Perfekte Symbiose
```

### **NOTFALL-OVERRIDE:**
```
[TAB] drücken in JEDER Stufe:
├─ → DIRECT COMMAND MODE
├─ → Commands wie Rookie (direkt!)
├─ → Najika führt SOFORT aus
└─ → [TAB] wieder = zurück zu Autonomie

WANN NUTZEN:
├─ Najika macht Fehler
├─ Notfall (niedrige HP)
├─ Boss-Finish (du willst selbst entscheiden)
└─ Du vertraust ihr nicht in dieser Situation
```

### **CONTROLS:**
```
[1-4] - Commands (stufen-abhängig)
[SPACE] - Praise (👏)
[CTRL] - Scold (😠)
[F] - Finisher
[TAB] - Override Toggle
[C] - Kamera wechseln
Maus - Kamera drehen/zoomen
```

### **IDEAL FÜR:**
- ✅ Entspanntes Spielen (Najika macht's)
- ✅ Strategisches Denken (Commander-Rolle)
- ✅ Beziehung aufbauen (Praise/Scold)
- ✅ Najika's Evolution beobachten
- ✅ Anfänger (wenn Rookie-Stufe)

## 👤 THIRD PERSON - ACTION-MODUS (Skyrim/Soulframe Style)

### **WAS IST DAS?**
Du **BIST** Najika. Volle direkte Kontrolle.
Über-Schulter-Kamera, du steuerst ALLES.

### **KEINE EVOLUTION:**
```
Immer gleich - keine Stufen!
├─ 100% direkte Kontrolle
├─ Keine Autonomie
├─ Du entscheidest jeden Move
└─ Wie Skyrim/Soulframe
```

### **CONTROLS:**
```
WASD - Bewegung
Maus - Kamera (Look Around)
LMB - Light Attack
RMB - Heavy Attack
SPACE - Dodge Roll
Q - Parry
SHIFT - Block
1-6 - Element-Weaving
[F] - Finisher (QTE)
[C] - Kamera wechseln
```

### **IDEAL FÜR:**
- ✅ Action-Fans (direkte Kontrolle)
- ✅ Schwierige Bosse (präzise ausweichen)
- ✅ Combo-Spieler (Light→Heavy→Parry→Riposte)
- ✅ Element-Weaving testen
- ✅ Finisher selbst ausführen

## 👁️ FIRST PERSON - EGO-MODUS (Skyrim/Soulframe Style)

### **WAS IST DAS?**
Du siehst durch **Najika's Augen**. Maximale Immersion.
Gleiche Controls wie Third Person, nur andere Perspektive.

### **UNTERSCHIED ZU THIRD PERSON:**
```
✅ Gleiche Controls
✅ Gleiche Combat-Mechanik
✅ Kein Override nötig (du bist Kontrolle)
❌ Aber: Weniger Übersicht
✅ Mehr Immersion
✅ Head-Bob beim Laufen
```

### **CONTROLS:**
```
Exakt wie Third Person!
Nur Kamera ist in Ego-Perspektive.
```

### **IDEAL FÜR:**
- ✅ Immersion (du BIST Najika)
- ✅ Exploration (Welt aus ihren Augen)
- ✅ Präzises Zielen (First-Person Shooter Feeling)
- ✅ Cinematic-Erlebnis

## 🔄 KAMERA-WECHSEL WÄHREND KAMPF

### **JEDERZEIT MIT [C] WECHSELN:**

```
ORBIT → THIRD:
├─ Najika kämpft autonom
├─ [C] drücken
├─ → Du übernimmst SOFORT
├─ → WASD/Maus Controls aktiv
└─ Najika: "Kuja! Du übernimmst?!"

THIRD → FIRST:
├─ Du steuerst Third Person
├─ [C] drücken
├─ → Kamera wechselt zu Ego
└─ Controls bleiben gleich

FIRST → ORBIT:
├─ Du steuerst First Person
├─ [C] drücken
├─ → Najika übernimmt wieder
└─ Commands erscheinen (Stufe-abhängig)

ALLE Kombinationen möglich!
```
