## ⏱️ TIMING-SYSTEM (Kombination!)

### **COMMAND-TIMING:**
```
Najika zeigt Indikatoren:
├─ ❗(Rot, pulsierend) → "JETZT angreifen!"
├─ 🛡️ (Blau, glühend) → "JETZT verteidigen!"
├─ ⚡ (Gelb, blitzend) → "JETZT Zauber!"
└─ 💨 (Grau, wackelnd) → "JETZT zurückziehen!"

Wenn du Command im richtigen Moment gibst:
✅ PERFECT TIMING (+30% Effektivität)
✅ "Ja, genau jetzt! Gut gesehen, Kuja!"
✅ Battle XP +5

Wenn du Command zu früh/spät gibst:
⚠️ OKAY TIMING (normal)
⚠️ "Hmm, ich versuch's..."

Wenn du Command im falschen Moment gibst:
❌ BAD TIMING (-10% Effektivität)
❌ "Nicht jetzt! Warte kurz!"
❌ Najika ignoriert oder verzögert
```
