# NAJIKA GAME - KURZ-ÜBERSICHT

**Für:** KI, Najika, Entwickler
**Zweck:** Schneller Überblick über ALLES

---

## KERN-FEATURES (NEU)

**Oregon Trail × Konosuba Chaos Engine**
- Zufällige Reise-Events (Oregon Trail) mit Konosuba-Chaos (absurde Wendungen, alles geht schief)

**Klassen-Spezialisierungs-Story-System**
- Jede Klasse/Waffe/1-Skill-Spezialisierung hat EIGENE Story-Linie

**Companion Creation System**
- Spieler erstellen eigene Begleiter mit Custom-Persönlichkeiten

**Persönlichkeit × Klasse = Einzigartige Stories**
- Klassen-Spezialisierung kombiniert mit Companion-Persönlichkeit
