### **ÄNDERUNGEN VORNEHMEN**

#### **1. KÖRPERGRÖSSE ANPASSEN**

```
1. Wähle Modell aus (Linksklick)

2. Skalieren:
   - Taste "S" drücken (Scale)
   - Zahl eingeben: 0.85 (15% kleiner)
   - Enter drücken

3. Proportionen prüfen:
   - Sollte jetzt ~140cm groß sein
   - Wenn noch zu groß: nochmal "S" → 0.9
```

#### **2. SOCKEN ENTFERNEN/VERKÜRZEN**

```
1. Tab-Taste: Edit Mode

2. Selektiere Socken-Mesh:
   - Klicke auf schwarze Socken
   - Oder: Box-Select (B-Taste + Ziehen)

3. OPTION A - Löschen:
   - X-Taste → Delete → Faces
   - Socken sind weg → nackte Beine ✅

4. OPTION B - Verkürzen:
   - Mit Proportional Editing nach unten ziehen
   - Nur kurze Socken über Stiefeln bleiben
```

#### **3. VERBAND HINZUFÜGEN (LINKES BEIN)**

**Methode A: Einfach (Plane)**

```
1. Add → Mesh → Plane

2. Skalieren:
   - S-Taste → 0.1 (klein machen)
   - S-Taste + Y → 3 (länger in Y-Richtung)

3. Positionieren:
   - G-Taste (Grab/Move)
   - Bewege zu linker Wade

4. Rotation:
   - R-Taste + Y → 45° (schräg um Bein wickeln)

5. Array Modifier (für Windungen):
   - Rechts: Modifiers → Add Modifier → Array
   - Count: 3 (3 Windungen)
   - Relative Offset Y: 1.5

6. Material: Weiß
   - Material Properties → New
   - Base Color: Weiß (#FFFFFF)
```

**Methode B: Detailliert (Curve)**

```python
# Python-Script für Blender Console:
import bpy
import math

# Erstelle Bandage als Curve
curve = bpy.data.curves.new('bandage', 'CURVE')
curve.dimensions = '3D'
spline = curve.splines.new('NURBS')

# Wickle um linkes Bein (Wade)
points = []
for i in range(20):
    angle = (i / 20) * math.pi * 6  # 3 Windungen
    x = -0.05 + math.cos(angle) * 0.08  # Links
    y = 0.5 + (i / 20) * 0.15           # Wade-Höhe
    z = math.sin(angle) * 0.08
    points.append((x, y, z))

# Erstelle Spline
spline.points.add(len(points) - 1)
for i, point in enumerate(points):
    spline.points[i].co = (*point, 1)

# Curve-Objekt erstellen
bandage_obj = bpy.data.objects.new('Bandage', curve)
bpy.context.collection.objects.link(bandage_obj)

# Bevel (Dicke geben)
curve.bevel_depth = 0.01
curve.bevel_resolution = 4

# Material: Weiß
mat = bpy.data.materials.new('Bandage_White')
mat.use_nodes = True
mat.node_tree.nodes["Principled BSDF"].inputs[0].default_value = (1, 1, 1, 1)
bandage_obj.data.materials.append(mat)
```
