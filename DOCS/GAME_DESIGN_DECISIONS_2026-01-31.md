## 🗺️ MAP-STRUKTUR (MEGA WICHTIG!)

### Grundkonzept:
```
START-MAP (Götterfels + Schwarze Mühle + 8 Teleporter)
    │
    ├── Najika sprengt Fels → KAMPFTURM erscheint
    │
    └── 8 TELEPORTER führen zu:
        ├── ICE MAP (eigene große Map!)
        ├── DESERT MAP
        ├── SWAMP MAP
        ├── COAST MAP
        ├── CAVES MAP
        ├── VOLCANO MAP
        ├── FOREST MAP
        └── HIGHLAND MAP

JEDE MAP:
- So groß wie die Start-Map!
- Eigene Städte
- Eigenes Biom
- Eigene Quests
- Bestimmte Gegenstände sammeln → TURM-EINLASS-KARTE
```

### Turm-Freischaltung:
1. Alle 8 Biom-Maps durchspielen
2. In jeder Map bestimmte Dinge sammeln
3. Kartenteile ergeben TURM-EINLASS-KARTE
4. Erst DANN Zugang zum Kampfturm!

### Fortnite-Umsetzung:
- Jedes Biom = eigene Creative Map
- Start-Map hat 8 Teleporter
- Portale zu den anderen Maps

## 🐾 SLIME-SYSTEM (FINAL!)

### Formen vs Attacken = GETRENNT!

```
FORMEN:
├── Reine OPTIK-Frage
├── Keine Kampf-Boni durch Form!
├── Boni kommen durch ESSEN/AUSRÜSTUNG
├── Form-Wechsel im SPIEL: 1x pro SAISON
└── Form-Wechsel ZUHAUSE (App): Unbegrenzt - NUR für Training!
    └── Nicht für Spielwelt! Nur zum Anschauen/Trainieren!

ATTACKEN:
├── Skills die man lernt
├── Unabhängig von Form
├── Training verbessert Skills
└── Von Monstern lernen durch Kampf
```

### Formen sammeln:
- Monster besiegen → kleine Chance auf Form-Drop
- NICHT geschenkt bekommen!
- Quest/Event = Form freischalten
- 1x pro Saison kann man Form im SPIEL WECHSELN
- Zuhause kann man Formen anschauen + damit trainieren (aber nicht ins Spiel mitnehmen!)

### Farben:
- **ERSTMAL RAUS!**
- Später: Seltene Drops von legendären Monstern
- Oder: Spezial-Events
- Farben = NUR OPTISCH, keine Gameplay-Effekte

## 🐄 ZÜCHTEN (Material-Zucht)

### Konzept (Minecraft-Style):
```
KEINE Kühe/Schafe! → Fantasy-Western MONSTER züchten!

Beispiele:
├── Wüsten-Echse → Schuppen, Leder
├── Sumpf-Molch → Schleim, Gift-Drüsen
├── Vulkan-Salamander → Feuerkern, Hitze-Fell
├── Eis-Hase → Kristall-Fell, Frost-Fleisch
└── Magische Kreaturen → Seltene Materialien
```

### Balance: Farmen vs Züchten
| Farmen (draußen) | Züchten (zuhause) |
|------------------|-------------------|
| Waffen nutzen sich ab | Futter-Kosten |
| Gefahr unterwegs | Aufzucht-Zeit |
| Ressourcen-Kosten | Platz-Bedarf |
| Qualität = Glück | Qualität = Pflege |

**Beide haben Vor- und Nachteile!**

## 💀 KOPFGELD-SYSTEM

### Fraktions-basiert (8 Regionen):
- Jede Region hat EIGENE Kopfgeld-Liste
- Held in Region A = Verbrecher in Region B
- Graue Moral wie Fallout!

### Steckbrief-System:
| Stufe | Name | Wer kommt? |
|-------|------|------------|
| 0 | Keiner | Niemand |
| 1 | "Kleiner Fisch" | Lokale Wachen |
| 2 | "Gefährlich" | Kopfgeldjäger-Anfänger |
| 3 | "Tot oder Lebendig" | Profi-Jäger |
| 4 | "Regions-Bedrohung" | Gebietherrscher schickt Elite |
| 5 | "Welt-Bedrohung" | ALLE 8 Gebietherrscher vereint! |

### Verhüllung (statt Verkleidung):
- KEINE magische Verwandlung (2m Typ wird nicht 80cm Zwergin!)
- Kapuze, Maske, Verschleierung
- NICHT 100% sicher!
- Auffliegen bei: Kampf, EXPLOSION, bekannte NPCs ansprechen

## 🏠 DIGIVICE MODUL-SYSTEM (SUPER WICHTIG!)

### Was ist das Digivice?
Das Digivice ist die HAUPT-APP auf dem Handy! Es ist wie ein virtuelles Gerät mit:
- 12 Räumen (3D navigierbar)
- 4 Terminal-Modulen
- Das Spiel als EIN großes Modul

### Architektur:
```
DIGIVICE APP (PWA auf Handy)
│
├── 12 RÄUME:
│   ├── Wohnzimmer
│   ├── Schlafzimmer
│   ├── Küche
│   ├── Badezimmer
│   ├── Garten
│   ├── Musikraum
│   ├── Medizin
│   ├── Terminal (Zugang zu 4 Modulen!)
│   ├── Studieren & Crafting
│   ├── Trainingszimmer
│   ├── Kampfarena
│   └── Schwarze Mühle - Keller (Najika's Zuhause!)
│
├── 4 TERMINAL-MODULE (aus Terminal-Raum zugänglich):
│   ├── 🔒 Sicherer Messenger (Militär-Verschlüsselung)
│   ├── 🌐 Sicherer Browser
│   ├── 🎮 HANDYSPIEL (das große Modul!)
│   └── ⚙️ System-Settings
│
├── LERN-MODULE (später):
│   ├── 🎸 Instrumente LERNEN (richtig!)
│   ├── 🗣️ Sprachen LERNEN (richtig!)
│   ├── 🏃 Sport-Tracking
│   └── etc.
│
└── SCHWARZE MÜHLE = Najika's Haus
    ├── Spieler trainiert hier mit Slime
    ├── Form-Wechsel zum Trainieren
    └── NSFW/Kätzchen-Modus (privat!)
```

### Das HANDYSPIEL-Modul enthält:
```
HANDYSPIEL (1 großes Modul mit ALLEM!)
├── Angeln (Spiel-Tiefe wie eigenes Spiel!)
├── Farming (Spiel-Tiefe wie eigenes Spiel!)
├── Housing (Spiel-Tiefe wie eigenes Spiel!)
├── Arena (Spiel-Tiefe wie eigenes Spiel!)
├── Triple Triad (Spiel-Tiefe wie eigenes Spiel!)
├── Crafting (Spiel-Tiefe wie eigenes Spiel!)
├── Oregon Trail Events
├── Dungeon System
└── Open World (8 Regionen + Götterfels)
```

### Wichtig:
- Digivice = Die App selbst (mit Räumen)
- Handyspiel = EIN Modul innerhalb des Digivice
- Jedes Sub-System im Spiel muss so tief sein, dass es ein EIGENES SPIEL sein könnte!
- Aber es sind KEINE separaten Spiele - alles ist IM Handyspiel-Modul!

## 🏟️ ARENA WELLEN-SYSTEM (WICHTIG!)

### Zweistufiges System:

```
STUFE 1: TRAINING (15 Wellen)
├── KEIN echter Tod!
├── Wenn besiegt → Auto-Rückzug / Vom Arena-Personal gerettet
├── Belohnungen: Minimal (vielleicht 1 Trank)
├── Zum Üben und Lernen gedacht
└── Nach Abschluss → FREISCHALTUNG von Stufe 2

ÜBERGANGS-SEQUENZ:
├── Wachen öffnen das Tor
├── "Jetzt beginnt die richtige Challenge!"
├── MEHRFACHE Warnung: "Wenn Tod, dann Tod!"
└── Spieler muss bestätigen

STUFE 2: ECHTER WELLEN-MODUS (Hardcore!)
├── Tod = echter Tod (Hardcore-Regeln)
├── Echte Belohnungen
├── Progression zählt
└── Gefährlich aber lohnend
```

### Wichtig:
- Training ist IMMER verfügbar
- Echter Modus erst nach 15 Training-Wellen
- Klare Trennung zwischen "sicher üben" und "echtes Risiko"

## ⚡ OFFLINE-FIRST KLARSTELLUNG (WICHTIG!)

### Was ist Offline-First?
**NUR für:**
- Digivice App (persönliche Najika)
- Alles was im Digivice möglich ist
- Lokale Features und Training

**NICHT für:**
- Das spätere Handyspiel (kann Online-Features haben)
- Multiplayer-Komponenten
- UEFN-Port (Fortnite)

### Grund:
Digivice = Persönliche KI-Companion, muss auch ohne Internet funktionieren
Handyspiel = Kann Online-Features nutzen wenn gewünscht

## 🥤 MONSTER KAUGUMMI - EXPLOSION GRAFIK (KORREKTUR!)

### WICHTIG: "EXPLOSION" als GRAFIK, nicht als Wort!

```
FALSCH:
┌─────────────────────────────────────┐
│      MONSTER ENERGY                 │
│           ✕                         │
│       EXPLOSION  ← TEXT             │
└─────────────────────────────────────┘

RICHTIG:
┌─────────────────────────────────────┐
│      MONSTER ENERGY                 │
│           ✕                         │
│       💥🔥✨  ← GRAFIK!             │
│   (Megumin-Style Explosion Art)     │
│       KAUGUMMI                      │
└─────────────────────────────────────┘
```

### Design-Vorgabe:
- EXPLOSION wird als GRAFIK dargestellt
- Wie Megumin's Explosion aussieht (dramatisch, farbenfroh)
- Nicht einfach das Wort "EXPLOSION" hinschreiben
- Visuell eindrucksvoll wie im Anime
