## 📝 UE5 LOCALIZATION SYSTEM

### **Setup Localization in UE5:**

```
1. Edit → Project Settings → Localization

2. Add Localization Target:
   Name: "Game"
   Loading Policy: Always

3. Add Cultures:
   ☑ German (de) - Default!
   ☑ English (en)

4. Gather Settings:
   ☑ Gather from Text Files
   ☑ Gather from Packages
   ☑ Gather from Metadata

5. Click "Gather Text" button
   → Scans project for all text
   → Creates .po files for translation

6. Translate in Localization Dashboard or external tool

7. Click "Compile Text" button
```

## 💬 TEXT MACRO SYSTEM (FText)

### **Using FText in Blueprints:**

```
WRONG (Hardcoded String):
❌ Set Text: "Hello"

CORRECT (Localized FText):
✅ Set Text: NSLOCTEXT("Game", "Greeting_Hello", "Hello")

PARAMETERS:
- Namespace: "Game" (or category like "UI", "Combat")
- Key: Unique identifier ("Greeting_Hello")
- Source: Default text ("Hello")

BLUEPRINT USAGE:
In WBP_ChatUI:
→ Text Block: Message
→ Set Text = FText from String Table
→ String Table: "ST_UI"
→ Key: "Chat_Send_Button"
```

---

### **String Tables (Recommended!):**

```
WHY STRING TABLES?
→ Easier to manage than NSLOCTEXT
→ Can be edited in CSV/JSON
→ Hot-reload (change text without restart!)
→ Better for large projects

CREATE STRING TABLE:
1. Content Browser → Right-click
2. Miscellaneous → String Table
3. Name: ST_UI (for UI text)

4. Add rows:
   Key              | Source String (DE)      | Metadat
a
   ───────────────────────────────────────────────────────
   MainMenu_Start   | Spiel starten          |
   MainMenu_Options | Einstellungen          |
   MainMenu_Quit    | Beenden                |
   Chat_Send        | Senden                 |
   Chat_Placeholder | Nachricht eingeben...  |

5. Export to CSV (for translation!)
6. Import translated CSV (English version)

USE IN BLUEPRINT:
→ Get String Table Entry
   Table: ST_UI
   Key: "MainMenu_Start"
   → Returns: "Spiel starten" (if language = DE)
```

## 🔤 TEXT FORMATTING & VARIABLES

### **Dynamic Text with Variables:**

```
PROBLEM: "You have 5 apples"
→ "5" changes, rest stays same
→ Need translation WITH variable!

SOLUTION: FText::Format

EXAMPLE:
Source (DE): "Du hast {Count} Äpfel"
Source (EN): "You have {Count} apples"

Blueprint:
Format Text:
  Format: Get from String Table (ST_Items, "Apple_Count")
  Arguments: Count = 5
  Result: "Du hast 5 Äpfel" (if DE)

STRING TABLE ENTRY:
Key: Item_Count
DE: Du hast {Count} {ItemName}
EN: You have {Count} {ItemName}

USAGE:
Format Text:
  Format: ST_Items["Item_Count"]
  Count: 5
  ItemName: "Äpfel" / "apples"
```

---

### **Pluralization:**

```
PROBLEM:
1 apple → "1 apple"
2 apples → "2 apples"
German: "1 Apfel" vs "2 Äpfel"

SOLUTION: Plural Forms

String Table:
Key: Item_Apple_Singular
DE: Apfel
EN: apple

Key: Item_Apple_Plural
DE: Äpfel
EN: apples

Blueprint:
If Count == 1:
  Use Singular
Else:
  Use Plural

ADVANCED (UE5 Plural Forms):
Format Text with ICU Syntax:
"{Count, plural, one{# Apfel} other{# Äpfel}}"
→ UE5 auto-handles based on language rules!
```

```
    data = request.json
    message = data.get("message")
    language = data.get("language", "de")  # NEW: Language parameter!
```

## 📱 LANGUAGE SELECTION

### **Settings Menu - Language Picker:**

```
WBP_SettingsLanguage:

UI LAYOUT:
┌─────────────────────────────────┐
│ 🌍 SPRACHE / LANGUAGE           │
│                                 │
│ (•) 🇩🇪 Deutsch                │
│ ( ) 🇬🇧 English                │
│                                 │
│ [Übernehmen / Apply]            │
│                                 │
│ Note: App wird neu gestartet    │
│       App will restart          │
└─────────────────────────────────┘

BLUEPRINT LOGIC:

OnLanguageSelected(LanguageCode: String):
  1. Save to settings: SetLanguage(LanguageCode)
  2. Show confirmation dialog
  3. If confirmed:
     → UE5: Set Culture (FInternationalization::Get().SetCurrentCulture(LanguageCode))
     → Reload UI (recreate all widgets with new text!)
     → Or: Restart app (simpler!)

PERSISTENCE:
SaveGame / EncryptedSharedPreferences:
→ Store "PreferredLanguage" = "de" or "en"
→ On app start:
   * Read PreferredLanguage
   * Set Culture
   * Load localized text
```

---

### **Auto-Detect System Language:**

```
FIRST LAUNCH:
→ Check device system language
→ If German: Use German
→ If English: Use English
→ Else: Default to German (primary)

BLUEPRINT:

Event BeginPlay (Game Instance):
  → Get Saved Language
  → If None (first launch):
     * Get System Language
     * SystemLang = Get Current Culture Name()
       → Returns: "de-DE", "en-US", etc.
     * Extract: "de" or "en"
     * If "de": Set to German
     * Else if "en": Set to English
     * Else: Set to German (default)
     * Save choice
  → Else:
     * Use saved language
```

## 🔄 TRANSLATION WORKFLOW

### **Step-by-Step Translation Process:**

```
STEP 1: DEVELOPMENT (Add text in PRIMARY language - German)
→ Create String Tables with German text
→ Use String Table keys in Blueprints
→ Test in German

STEP 2: GATHER TEXT
→ Edit → Project Settings → Localization
→ Click "Gather Text"
→ UE5 scans project, creates .po files

STEP 3: EXPORT FOR TRANSLATION
→ Open Localization Dashboard
→ Export → CSV (or PO for professional translators)
→ File: Game_de.csv, Game_en.csv

STEP 4: TRANSLATE
→ Open Game_en.csv in Excel/Google Sheets
→ Translate German → English
→ Save

EXAMPLE CSV:
Key,Namespace,Source,Translation
MainMenu_Start,Game,Spiel starten,Start Game
MainMenu_Options,Game,Einstellungen,Settings

STEP 5: IMPORT TRANSLATIONS
→ Localization Dashboard
→ Import → Select Game_en.csv
→ Import

STEP 6: COMPILE TEXT
→ Click "Compile Text"
→ Creates .locres files

STEP 7: TEST
→ Change language in settings
→ Verify all text translated
→ Fix any missing translations

STEP 8: ITERATE
→ Add more text during development
→ Re-gather, re-translate, re-compile
→ Continuous process!
```
