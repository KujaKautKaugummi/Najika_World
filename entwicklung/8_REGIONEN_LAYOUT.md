**Erstellt:** 2025-11-07
**Weltgröße:** 9600 x 9600 (4x Vergrößerung)
**Berg-Position:** Zentrum (4800, 4800)
**Status:** Design Phase

---

## 🎯 KONZEPT

**Najikas Mini-Open-World = Miniatur-Version der großen 8-Regionen-Welt**

- **Berg bleibt in der Mitte** (unveränderlich)
- **Nur die Spitze ändert sich:** Schwarze Mühle → später Zeitstadt (Handyspiel)
- **8 Regionen rund um den Berg** (verkleinerte Versionen)
- **Jede Region Level 1-15** (gleiche Start-Schwierigkeit)
- **Dient als Test-Environment** für Housing/Farming/Fishing/Crafting

## 🚀 FAST TRAVEL SYSTEM

```yaml
Konzept:
  - Schwarze Mühle = Fast Travel Hub
  - Von Mühle zu jeder Region teleportieren

Unlock:
  - Region besuchen → Fast Travel freischalten
  - Oder: Teleport-Steine in Regionen finden

Kosten:
  - Gratis von Mühle zu Regionen
  - Kosten für Region → Region (ohne Mühle)

Shrines (wie Zelda):
  - Jede Region hat 3-5 Shrines
  - Aktivieren = Fast Travel Punkt
```

## 📊 PROGRESSION

### Erste Schritte:
```yaml
1. Start auf Berg (Schwarze Mühle)
2. Tutorial: Najika erklärt Grundlagen
3. Wähle Start-Region (alle 1-15!)
4. Erkunde, farme, fische, baue
5. Schalte andere Regionen frei
```

### Slime-Metamorphose:
```yaml
1. Zufälliges Fantasy-Tier (Level 1-49)
2. Level 50 + Kritisches Event
3. Metamorphose in der AKTUELLEN Region
4. Slime nimmt Farbe der Region an!
5. Sammle alle 8 Farben → Rainbow-Slime
```

### Endgame:
```yaml
1. Alle 8 Regionen erkundet
2. Rainbow-Slime erhalten
3. Götterfels Innen freigeschaltet
4. Schmelz-Welt betreten
5. Turm der 100 Prüfungen (nach Najika's Explosion)
```
